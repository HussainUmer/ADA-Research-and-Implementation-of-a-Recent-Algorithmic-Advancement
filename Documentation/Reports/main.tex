\section*{Summary}
This paper presents a randomized algorithm for solving the Single-Source Shortest Paths (SSSP) problem on directed graphs with real edge weights, both positive and negative. The key contribution is an improved running time of Õ(mn$^{8/9}$), where $m$ is the number of edges and $n$ the number of vertices, which improves upon the Bellman-Ford algorithm's O(mn) time by using Djisktra Algorithm.

\section*{Justification}
This paper's novel time complexity improvement for SSSP is relevant to graph-based optimization problems, including network analysis and routing. It offers a practical improvement for graphs with real weights and negative edges. And it aligns with one of the topics in our course syllabus.

\section*{Implementation Feasibility}
The paper provides detailed theoretical descriptions of the algorithm. While no direct code is available, existing algorithms like Bellman-Ford and Djisktra can serve as a foundation for implementation.

## Summary:
This paper presents a randomized algorithm for solving the Single-Source Shortest Paths (SSSP) problem on directed graphs with real edge weights, both positive and negative. The key contribution is an improved running time of Õ(mn$^{8/9}$), where $m$ is the number of edges and $n$ the number of vertices, which improves upon the Bellman-Ford algorithm's O(mn) time.
